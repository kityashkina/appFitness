# appFitness

Настольное приложение для управления услугами фитнес-студии.  
Разработано на C# (WPF, .NET Framework 4.8) с базой данных MS SQL Server.

## Возможности

Приложение поддерживает три роли пользователей:

- **Администратор** — ведёт клиентскую базу, просматривает абонементы и расписание, добавляет занятия
- **Менеджер** — управляет занятиями, залами и абонементами, имеет все права администратора
- **Тренер** — просматривает своё расписание на текущую неделю, отмечает посещения клиентов

## Технологии

- C# / WPF / .NET Framework 4.8
- MS SQL Server
- ADO.NET
- MSTest (модульное тестирование)
